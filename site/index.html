Agent-Grammar

Validation layer for AGenNext schema:CreativeWork artifacts.

Purpose

Agent-Grammar validates whether prompts, skills, API docs, blog posts, READMEs, policies, protocols, tutorials, and other CreativeWorks are structurally valid before they enter their target repositories.

Separation

Agent-Vocabulary = words / DefinedTerms
Agent-Graph      = relationships between words
Agent-Grammar    = validation rules
Prompt-Library   = accepted CreativeWork artifacts

Core Rule

A file is accepted as an AGenNext CreativeWork only after it passes Agent-Grammar validation.
